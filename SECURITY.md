# Политика безопасности

## Учебный проект — читайте внимательно

Репозиторий содержит **намеренно уязвимое API** (`main.py`) для обучения DAST-сканированию.

- **Не разворачивайте учебную цель в публичном интернете.** Она уязвима по замыслу.
- Сканер по умолчанию работает на `127.0.0.1`. При публичном деплое обязательно задайте
  `SCANNER_ADMIN_PASSWORD` и `SCANNER_GUEST_PASSWORD` (иначе admin/admin).
- Для публичного деплоя сканера включите: `SCANNER_COOKIE_SECURE=1`, `SCANNER_HSTS=1`,
  `SCANNER_TRUST_PROXY=1` (за TLS-прокси), ограничьте `ALLOWED_HOSTS`.
- `SCANNER_ALLOW_PRIVATE_TARGETS=1` по умолчанию разрешает сканировать внутренние адреса
  (нужно для локальной цели). Для публичного сканера установите `0` — включится строгая
  SSRF-защита (fail-closed).

## Сообщить об уязвимости в самом сканере

Нашли проблему в коде сканера (не учебной цели)? Откройте приватный security advisory:
**Security → Report a vulnerability** в репозитории, либо issue с пометкой `security`.
Не публикуйте PoC для реальных целей до исправления.

## Ротация токенов

Если вы использовали GitHub-токен для автоматизации (push/PR/merge) — отзовите его после
работы (Settings → Developer settings → Tokens) и выпустите новый с минимальным scope.
